# Spaciel sourcebook working inventory — 608 reconciliation

The older discussion cited **608 sourcebook locations**. The active map dataset has **556** locations, each now carrying a non-empty display tag and a unique ID in the [corrected register](../data/locations/spaciel_locations_556_corrected_2026-11-10.json).

A **plausible 608-entry working inventory** is:
- 556 location records with existing map positions.
- 51 individually numbered attractions under *Playland by the Sea* in the sourcebook (see PDF pages 303–312).
- 1 parent venue: Playland by the Sea itself, treated as a separate unnumbered map candidate.

**556 + 51 + 1 = 608**, but we have **not independently verified** that this is precisely how the earlier 608 was counted. The Playland parent is provisional, and attraction numbers **31** and **39** still require name verification from the original artwork/page layout.

See [deferred Playland inventory](../data/locations/spaciel_playland_deferred_2026-11-10.json) for all 51 numbered slots and the provisional parent. Of 51 slots, 49 have a name transcribed from the sourcebook and 2 remain deliberately unnamed. All have a **generic placeholder display tag**, but none has atlas coordinates and none has been added to the viewer. User had previously chosen to postpone individual Playland attractions as a later expansion.

**Practical conclusion:** the current 556 mapped locations are fully covered by IDs and tags. The broader nominal 608 count now has an explicit, transparent reconciliation rather than 52 invented map pins.
