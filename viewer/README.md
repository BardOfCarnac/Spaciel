# Spaciel viewer builds

## Latest private architectural recovery — Realisation 11 (11 November 2026)

**All 4,470 source building definitions in the working screened catalogue now have direct-face geometry recovered from the original SketchUp source.** This includes 1,291 newly extracted, valid GLBs in the latest pass: 533 additional large definitions with source footprints at least 500 m² (five still flagged for envelope repair) and 758 smaller ones. This does **not** confirm complete nested SketchUp components, finishes or independently validated final building sites.

The private Realisation 11 landmark reviewer offers **633 unplaced large definitions**, **656** rough original-instance position references and a narrow **27-model / 28-instance urban restoration shortlist**. No new large buildings were automatically inserted. Source-site registration and many road/coastline conflicts remain provisional, so the review suggests where selective displacement of smaller masses might restore the skyline. [Read the Realisation 11 report](../reports/native_skp_realisation_11_complete_source_catalogue_2026_11_11.md).

The city baseline remains **7,993 provisional building placements**, including **7,981 registered native direct-face mesh uses** in **60** architecture tiles; 11 shoreline holds and one protected Hot Zone mass remain. **556 location tags**, unified geographic search, V17 offline roads and experimental V21 remain unchanged.

Private HTML, modular ZIP, 1,291 supplemental original-source GLBs, QA and screenshots are in ChatGPT Library `/Spaciel/working-data/`. Standalone desktop/mobile interaction checks passed; real-device WebGL2 rendering and direct HTTP modular loading have not been established.

## Public code, private model data
Public `viewer/src/` contains only source-independent loaders, tile selection and placement preview helpers. Do **not** publish the original SKP, derived meshes/GLBs, private viewer HTML, spatial tiles, source-site coordinates, contact sheets or asset catalogues without checking source redistribution rights.
