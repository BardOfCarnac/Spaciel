# Spaciel viewer builds

## Latest private staged skyline — Realisation 12 (11 November 2026)

A separate **reversible architectural review** has reinstated **2** missing original SketchUp buildings (36 m and 105 m high) near their approximate original positions, with **5** smaller existing source-model building placements locally repacked. No original buildings were deleted or stretched, and the Realisation 11 city baseline remains unchanged.

The staged alternate viewer contains **7,995** building objects, **7,983** original-source direct-face 3D mesh placements in **60** tiles, **556** location tags, the existing V17 road fallback and the experimental online V21 attempt. **26** other original-instance candidates were deliberately held because the adjacent buildings or road/shoreline rules did not permit a complete safe repack.

A standalone HTML, modular private ZIP, before-and-after visual and reversible placement/audit package are saved in the private ChatGPT Library folder `/Spaciel/working-data/`. Desktop/mobile fallback viewer interactions passed. Source-face GPU/WebGL2 device rendering and true hosted modular loading remain to be verified.
