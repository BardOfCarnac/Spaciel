# Spaciel viewer builds

**Integrated mockup (11 November 2026):** roads + buildings + location tags is available in the private Spaciel Library, not published from this public repository.

The full working mockup includes 7,993 building placements, 1,304 original-source mesh placements, V17 roads with online V21 trial, and 556 tagged place pins with searchable streets and districts.

The single-file viewer and a private modular package are preserved under `/Spaciel/working-data` in ChatGPT Library. The public integration details are in [the report](../reports/roads_buildings_tags_integrated_mockup_2026_11_11.md).

**Publication boundary:** the complete HTML and modular data package contain geometry derived from an original SketchUp source with unconfirmed redistribution rights. Never publish those files, the private geoJSON, or original mesh library in this public repository. A public-code-only viewer can be added once private data loading is separated and its behaviour tested.
